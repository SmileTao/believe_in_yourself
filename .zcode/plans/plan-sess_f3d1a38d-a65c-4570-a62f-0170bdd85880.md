# 「士别三日」深色科技风重设计 + AI 资讯模块

## 一、UI 重设计:现代深色科技风(Linear/Arc 风格)

**策略:沿用现有 Less token 体系,只改 token 值 + 少量样式文件**,让全部模块自动换肤,避免重写所有组件。

### 1. `src/theme/variables.less` — 全套替换为深色 token
- 背景:`@bg: #0A0E14` / `@bg-2: #0D1220`,带细微径向渐变光晕
- 卡片:`@surface: #131A26`(半透明玻璃拟态 `rgba(19,26,38,0.72)` + `backdrop-filter: blur`)
- 主色:保留品牌绿但调为霓虹感 `@primary: #34D399`、`@accent: #22D3EE`(青色点缀),渐变改为 `#34D399 → #22D3EE`
- 文字:`@text: #E6EDF3`、`@muted: #8B98A9`;边框 `@border: rgba(148,163,184,0.14)`
- 阴影改为深色投影 + 主色辉光(glowlg shadow)
- 侧边栏:深色 `#0C111B`,激活项用渐变描边 + 微光背景
- 追加玻璃卡片 mixin(`.glass-card`)

### 2. 同步更新的运行时主题
- `src/theme/theme-tokens.ts` + `src/theme/echarts-theme.ts`:坐标轴/文字/tooltip 改为深色配色,网格线半透明
- `src/theme/global.less`:滚动条深色化、body 背景加渐变光晕、`::selection` 主题色
- `src/App.less`:侧边栏玻璃质感、导航激活态渐变指示条、品牌标识霓虹渐变字
- 各模块 `.less` 只做微调(去白底硬编码、emoji 装饰改为 lucide 图标风格),不做大改

## 二、AI 资讯模块(全新)

### 数据层(主进程)
1. **新增依赖** `fast-xml-parser`(解析 RSS/Atom,轻量)
2. **RSS 源**(内置,后续可在设置扩展):机器之心、量子位、36氪-AI频道、Hacker News Front Page、The Verge AI
3. **`electron/news/newsService.ts`**:用 Electron `net.fetch` 抓取各源 → 解析 → 去重(按链接) → 按发布时间排序
4. **SQLite 持久化**:`migrations.ts` 新增 `news_items` 表(id, title, link, source, summary, published_at, fetched_at);新增 `repositories/news.ts`;启动时及每 6 小时自动拉取(失败静默降级,UI 显示上次缓存)
5. **IPC**:`news:refresh`、`news:list(limit)`、`news:todayHeadlines`;`preload.ts` 暴露 `api.news.*`;`shared/contracts` 补接口与类型;`electron/main.ts` 注册 handler,点击原文用 `shell.openExternal`

### 前端(Dashboard 主页)
1. **`NewsCarousel.tsx`**(新):置于 Dashboard 顶部,取当日最新 5 条头条做总结性轮播卡片——大字标题 + 来源 + 时间,5 秒自动切换(悬停暂停),带渐变进度指示点,点击 `window.open` 跳原文
2. **`NewsList.tsx`**(新):资讯列表,来源标签 + 标题 + 摘要(单行截断)+ 相对时间,整行可点击跳原文;顶部"刷新"按钮手动拉取;空态/离线态显示缓存时间
3. **Dashboard 布局调整**:轮播在最上方通栏,下方左右分栏(左侧原有的今日完成环 + 三只青蛙,右侧快速打卡),资讯列表放右下或底部通栏(实现时按视觉最佳排布)
4. 新增 `src/hooks/useNews.ts` 调 IPC

### 导航
- 在「今日」与「计划」之间不需要新页签——资讯完全集成在主页;若列表较长,Dashboard 内部滚动

## 三、实施顺序
1. 主题 token 重构(variables/global/App.less/theme-tokens/echarts)→ 逐模块微调样式
2. 主进程 news 服务 + 迁移 + IPC + preload + 契约
3. Dashboard 轮播 + 列表组件
4. `npm run typecheck` 验证,`npm run dev` 用浏览器自动化截图检查视觉效果并迭代

## 风险与说明
- RSS 源若个别失效,服务层做容错跳过,不影响其他源
- 深色化后部分模块可能有小块对比度问题,会在截图验收阶段逐个修正
- 不改任何既有业务逻辑与数据库表(仅新增 news_items)
